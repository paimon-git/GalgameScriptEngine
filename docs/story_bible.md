# 《星屑祭典》世界观与剧情树设计

> 这份文档是**剧情总纲**：世界观、背景故事、角色课题、剧情树结构与解锁规则。
> 剧本文件放在 `assets/scripts/`，一个 `.gal` = 剧情树上的一个**大章节**，文件里的 `chapter` 块 = 小章节。
> 玩家扮演**吴鸿韬**（第一人称"我"），从高二的秋天一路走到高三的夏天。

---

## 0. 一句话

**在一个把星星弄丢了的镇子上，一群高中生用了七十六年，把抬头这件事重新变成传统。**

---

## 1. 结构上参考《蔚蓝档案》的哪几件事

借的是**叙事结构**，不是设定：

| 《蔚蓝档案》的结构 | 本作对应 |
| --- | --- |
| 一个封闭而有规则的主舞台 | 青云镇 + 青云高中（外加云台山、市里、省科协） |
| 秩序机构与社团政治（联邦学生会 / 各校学生会） | 校务会、学生会（张誉腾）、市文旅（星野文旅）、省科协 |
| 社团 = 主角方，靠"事件"一卷一卷推进 | 天文社；三卷 = 废部 → 拆除 → 灯光秀 |
| 日常轻喜剧 + 硬核世界观的反差 | 海报、招人、修齿轮 vs 云志、守夜人、76 年的观测链 |
| 玩家角色被所有人依靠（老师位） | 吴鸿韬 = 社长 / 守夜人，所有人把话交给他 |
| 主线推进解锁角色个人剧情（羁绊） | 主线看章数解锁支线，支线解开角色的个人课题 |
| 大型活动收束（总力战） | 观测会 / 认定前夜 / 英仙座那一夜 |
| 敌人不是恶人，而是"更大的秩序与惯性" | 拆楼的预算、夜游经济的灯、家长对"有用"的定义 |

**不做的事**：不写打斗、不写超能力、不写反派阴谋。本作的"战斗"是**把一件事做完并留下证据**。

## 2. 舞台

### 2.1 青云镇

云台山脚下的小镇，常住两万余人。老产业是**光学磨镜与钟表修理**（镇上现在还开着三家钟表店、一家磨镜作坊），所以"用眼睛和手做事"是这个镇子的老底子。

近十年的变化：旅游开发、路灯改造、夜游经济。**镇子一年比一年亮**。

### 2.2 青云高中

建校 76 年。第一批校舍的最东头，原本是**一间观测站**：一个圆顶、一台赤道仪。

后来没人观测了，它被叫作"旧校舍"。再后来（第二部）它被重新认定为**青云天文馆**。

### 2.3 云台山与云台天文台

镇外的山。山背面的**云台天文台**是省城大学的教学台，魏思远在那里读天文系。山上没有灯，是全作最重要的取景地——**只有站在离开镇子的地方，才看得见镇子有多亮**。

### 2.4 机构与势力

| 势力 | 立场 | 代表人物 |
| --- | --- | --- |
| 天文社 | 主角方，十一个人 | 吴鸿韬、黎璘、梁知奕、尹博涛、李君浩、李俊辰、顾星禾、沈砚 |
| 学生会 | 讲规则，但讲规则的人是张誉腾 | 张誉腾 |
| 校务会 | 预算与安全，永远在"按流程办" | （不露面） |
| 星野文旅 | 第三卷的对手：想做星空灯光秀的市属公司 | （不露面） |
| 省科协 | 第三卷的转机：评"暗夜科普基地" | （不露面） |
| 云台天文台 | 外部支援 | 魏思远 |
| 天文社顾问 | 体制内的自己人 | 邵清和 |

## 3. 背景故事（核心设定）

### 3.1 云志

建校那年，第一批师生立下一条规矩：

> **每天记一次云。云量、风、能见度。一天不落。**

这条记录链叫**云志**。它的写法很笨：一本观测日志，写满为止，换下一本；每本只在**最后一页签名**。

七十六年下来，存下来的有一百多本，散在图书馆旧刊室、教师办公室、天文馆的玻璃柜里。

云志真正记的不是云，是**"我们还能看见多少"**。

### 3.2 守夜人

不写在任何文件上的身份：**谁把这条链接着往下写，谁就是守夜人**。

已知的传递（一代一代都只在日志最后一页留名）：

```
周文远（周老师）  → 邵清和 → 魏思远 → 吴鸿韬 → 顾星禾 / 沈砚
```

吴鸿韬在第二卷第三章第一次听到"守夜人"这个词；第三卷第八章把社长章和观测日志一起交出去。

**周文远（周老师）**：教了三十一年物理，31 年前签收了那台赤道仪（缺的那颗齿轮，
他到病倒都没装上）。十年前那场雨，全校没人来，是他一个人站在雨里陪邵清和到天亮，
第二天高烧住院。去年冬天他去世，**没有孩子**，把编号 **097** 的观测日志留给了
住在旧校舍楼下的吴鸿韬——最后只写了半行：

> 「十一月十七日。装好了，可是今晚有云。」

卷一整部的真正目标，就是**把这半行字写完**。卷四第三章，他的名字被顾星禾悄悄存进了
云志的数字档案；展柜上的纸牌写的仍是"编者不详"。

### 3.3 闭灯夜

青云镇的老规矩：**十年一次，全镇熄灯一小时，看银河**。

最后一次是二十一年前（吴鸿韬出生那年）。之后镇上换了三排路灯，没人再提。

第三卷的结尾（英仙座之夜）就是把这条规矩**续上**：1126 人上山，全镇照明负荷下降 41%。

### 3.4 圆顶与赤道仪

- 圆顶：76 岁，建校那年砌的。
- 赤道仪：31 年前由周老师签收，中途缺了三十多年的齿轮（第一卷李君浩修好）。
- 这两样东西在第二卷面临一起被拆掉，最后被认定为历史建筑。

### 3.5 三场"天气事件"（全作的关键时间点）

| 时间 | 事件 | 影响谁 |
| --- | --- | --- |
| 31 年前 | 周老师装好赤道仪，写下"装好了，可是今晚有云" | 邵清和（继承） |
| 10 年前 | 那场雨。高中观测会无人到场，邵清和离开天文圈 | 邵清和、魏思远 |
| 现在 | 三卷的三个夜晚：文化祭的十一分钟、拆除前的十七分钟、英仙座的三小时 | 全员 |

### 3.6 "灯"——不是反派，是惯性

全作没有坏人。对手永远是同一件东西：**更亮的灯**。

它有三种面孔：校务会的预算、市文旅的夜游经济、家长口中的"有什么用"。

主角们要做的不是把灯砸了，而是**让人自己想关灯**。

## 5. 角色档案

> 其他人的课题各自成线，主线里只露一角，支线里讲透。

| 黎璘 | 青梅竹马 · 图书馆委员 | 一个人记了两年云 | 她记云到底是为谁 | **《云志》✅已写** |

| 尹博涛 | 田径队王牌（跟腱断裂） | 跑不回十一秒二了 | 从"被需要跑"到"教人跑" | **《十一秒二》✅已写** |
| 李君浩 | 高一 · 钟表店之子 | 手比嘴快 | 父亲要他继承店 vs 他自己想修更大的东西 | **《齿轮与发条》✅已写** |

### 6.3 支线（七条全部已写）

**《十一秒二》（尹博涛 · 3 章）** — 起点：跑道 · 旧秒表；冲突：他回不到十一秒二；
落点：他把秒表从"自己成绩的刻度"变成"教别人进步的刻度"。

**《云志》（黎璘 · 3 章）** — 起点：旧刊室那本 51 年前的观测日志；
冲突：她记了十年云，一直以为是在替吴鸿韬记；落点：原来这是她家在断了三十年之后，又有人把它接了上去。
两人在天文馆的展柜里摆上那本日志，中间空着的三十年也一起展着。

**《齿轮与发条》（李君浩 · 3 章）** — 起点：镇上的钟表店要盘出去，柜台上摆着一只二十年没人来取的怀表；
冲突：配件早就不做了，他要手工绕一根游丝（绕断两百多根）；
落点：表走起来了，他爸说"你手比我稳"，把学徒时做的第一颗齿轮给他——他不继承店，但把这门手带去做精密仪器。

**《一百二十七张》（李俊辰 · 4 章）** — 起点：他把被撕碎的海报按颜色分成几堆，想拼回去；
冲突：学校要他写检查，他爸从厂里赶来，问"你画的这些东西，有人看吗"；
落点：他在天文馆后面的墙上画了二十四米长的十二月星图，墙角署上自己的名字——"俊是俊，辰是辰，别写错"。

**《那场雨》（邵清和 · 3 章）** — 起点：每年那天下雨，他都一个人站在操场中间；
冲突：十年前那晚他记了四十三页"雨"，天亮前写下"今晚没有星星。但记录是真的"；
落点：山上周老师的碑前摆着十年十块石头，今年他放下第十一块，第一次开口说话。

**《签字的人》（张誉腾 · 4 章）** — 起点：毕业去向登记表，"第一志愿：公共管理"；
冲突：他留着当年签废部通知前练名字的那张草稿纸；饭局上长辈说"孩子们就爱搞没用的"，他第一次顶了回去；
落点：毕业式上他说"签字的人，也得抬头"，把草稿纸交出去——"下次要签名的时候，用背面"。

**《拍星星的人》（顾星禾 & 沈砚 · 3 章）** — 起点：顾星禾的镜头摔碎了，三个月的照片卡在卡里；
冲突：暗房里两个人交换各自的失败（她初二那年因为凑不够五个人没看成的流星雨；他背错了那句话被人笑了一星期）；
落点：云志第二册记满的那天，最后一页签了两个名字。

### 6.4.1 卷一《星屑祭典》的"刀"（第二稿修订）

卷一一共加了四处硬刀，全部围绕周文远：

1. 第一章——吴鸿韬留在天文社的真正理由：把 097 那半行字写完（"说了，就像在找理由"）。
2. 第三章——赤道仪内壁刻着「周文远 · 十一月十七日」；齿轮是他刻了一半停下的。
3. 第四章——黎璘记云的原因：吴鸿韬有 137 天没来活动室，"我怕你以后都不来了"。
4. 第五章/第七章——邵清和的调离申请（"台下没人我就走"），
   以及雨夜的真相（"台下一个人都没有。……不，有一个人"→ 周文远站着陪了他一整夜）。

第八章结尾补了一刀：写完那半行字以后，"只是有人等到最后，也没等到。
所以我们这些等到了的人，得替他们，多抬头看一会儿。"

### 6.5 解锁规则（引擎里已经实现）

`.gal` 头部可以写剧情树元信息：

```gal
title "支线 · 云志"
series 星屑祭典
branch side                  # main = 主线，side = 支线
order 12                     # 同系列内排序
subtitle "黎璘 · 云志"        # 卡片副标题
requires star_festival_winter:8   # 前置：该脚本的第 8 章已观看
```

规则：

1. 章节选择的一级界面是一棵**可自由缩放 / 拖动平移的剧情树**（滚轮缩放、按住拖动、`R` 复位）：
   **主线横着一条**在屏幕中间（四卷串成一条蓝线），
   **支线竖着一条条**从各自的卷上垂下来/升上去（金线，卡片依次挂在线上），
   每卷的支线在上下对半分，整棵树更矮也更对称；
   解锁条件直接写在卡片上，不满足的锁住。
3. `requires` 没满足的卡片**锁住**（压暗 + "未开启"），解锁条件写在**进入这张卡的那条线**上
   （主线卷写在与上一卷之间的横线上方，支线写在垂下来的竖线旁边），一条条件一行；
4. 进度记在 `progress.dat`（每行 `脚本路径|章节号`），所以解锁是跨部的。

## 6.6 观测战（战斗系统）与剧情的关系

每一卷、每条支线的高潮里都插了一场**观测战**——把"灯 / 云 / 杂讯"这些对立面具象成敌人，
打法上就是回合制指令战斗（3 人小队、SP、技能），叙事上它是**"把这件事做完"的隐喻**：

| 战斗 | 在哪 | 敌人 | 出战 | 赢了 / 输了 |
| --- | --- | --- | --- | --- |
| 云层的阻挠 | 卷一 第七章 | 积云、夜雨 | 吴鸿韬 黎璘 梁知奕 | 赢：云让路；输：只抢到四分钟，邵老师补记录 |
| 拆除前夜 | 卷二 第七章 | 重云、雪压 | 吴鸿韬 尹博涛 李君浩 | 赢：北风早到六分钟；输：记录断两段，李君浩去接备用电瓶 |
| 英仙座之夜 | 卷三 第七章 | 灯海、霓虹 | 吴鸿韬 顾星禾 沈砚 | 赢：全镇灯退；输：还有几条街没关 |
| 闭灯夜 | 卷四 第七章 | 灯火、长夜、杂讯 | 吴鸿韬 邵清和 顾星禾 | 赢：沿河灯带全灭；输：还有店亮着，顾星禾对着亮处拍照 |
| 十一秒二 | 支线 尹博涛 | 旧纪录 | 吴鸿韬 尹博涛 | 赢：甩开旧纪录；输：慢就慢，反正跑完了 |
| 云志的空白 | 支线 黎璘 | 空白 | 吴鸿韬 黎璘 | 赢：柜锁一次对上；输：展签写歪三次 |
| 停摆的怀表 | 支线 李君浩 | 停摆 | 吴鸿韬 李君浩 | 赢：铜丝绕完最后一圈；输：又断一根，再来一次 |
| 画不出来的墙 | 支线 李俊辰 | 褪色 | 吴鸿韬 李俊辰 | 赢：收笔干净；输：有一段画歪了，"天上本来也不规整" |
| 山上的雨 | 支线 邵清和 | 连夜雨 | 吴鸿韬 邵清和 | 赢：雨停半分钟；输：雨更大，他站在原地没躲 |
| 一纸驳回 | 支线 张誉腾 | 驳回意见 | 吴鸿韬 张誉腾 | 赢：把两页纸捏紧又松开；输：准备好的话全不合适，那就只说一句 |
| 噪点 | 支线 顾星禾 & 沈砚 | 噪点 | 顾星禾 沈砚 | 赢：稿子没用上；输：卡了一下，停一下再接着讲 |

**设计原则**：战斗的结果**不改变主线走向**（输了也往下走，只是那一晚过得更狼狈），
这样既不会让玩家卡在战斗上，又让每一场战斗在情绪上是有分量的。
数值上用 `--check-battle` 保证"每场都能在回合上限内分出胜负"。

## 7. 玩家角色（吴鸿韬）视角规范

- **旁白 = 他的内心**：第一人称，短句，不解释情绪，只写他看见的。
  - ✅「我站在楼下，数它的窗户。一、二、三——」
  - ❌「我感到非常难过。」
- **他的台词要少、要钝**：一句话解决一件事，通常不超过 20 个字。
- **选择项 = 他的态度**：一律两项，不是"对/错"，而是"硬一点 / 软一点"。
  每个选择都必须真的改变一段对话（写进 `@标签`），不能只是风味文本。
- **他不能被夸奖**：别人怎么说他，他要么回一句无关的，要么沉默。
- **每章结尾留一个钩子**：一句旁白，或一个新出现的名字。
